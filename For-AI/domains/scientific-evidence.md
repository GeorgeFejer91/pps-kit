# Scientific evidence

Own published-method interpretation, profile fidelity, literature ledgers,
analysis assumptions, and research/publication claims. A UI-only task normally
does not need this domain.

## Read for the task

- Paper audits: relevant README under `For-AI/research/literature/`, then the
  named source card and ledger.
- Profile support: approved templates in `packages/pps-resources/` and
  research screening/evidence under `For-AI/research/literature/`.
- Scientific fields/materialization: matching
  [segment contract](../segment_registry_contract.md) and owning implementation
  from [module_map.md](../module_map.md).
- Validation claims: [validation tiers](../engineering/validation/docs/VALIDATION.md)
  and the actual report for the claimed scope.
- Manuscripts: the relevant workspace under `For-AI/research/publication/`.

Use **consensus-mcp** first for papers/evidence, discovering Consensus tools
when absent. Use **multi-source-web-search** for current documentation and
primary-source fallback under the Consensus rules. Use **academic-writing-style**
for scholarly drafting and artifact skills only for the actual format requested.

## Research-grade contract

Separate reported parameters, justified derivations, defaults, missing inputs,
and unsupported apparatus. Preserve source/page pointers, SOA anchors,
baseline/catch allocations, response semantics, and original-asset limitations.
Read current ledgers for counts rather than historical prose.

Software/emulated outcomes, physical timing, participant perception, and
observed behavioral replication are distinct tiers. Synthetic data/runnable
templates cannot demonstrate a published PPS effect. Simplification must
retain validation and calibration.

Track compact provenance/verdicts/blockers. Raw papers, extracted text,
participant data, recordings, and generated runs stay ignored. Only reviewed
public catalogue projections enter product assets. Update the owning source,
ledger, and focused checks; do not append research narratives to startup memory.
