# Publication Workspaces

[PPS Kit paper](https://github.com/GeorgeFejer91/pps-kit-paper) is the private
companion repository for the Toolkit's software and methods paper and related
conference abstracts. Start with its [working abstracts](https://github.com/GeorgeFejer91/pps-kit-paper/blob/main/abstract.md).

From the directory containing your `pps-kit` checkout, clone the paper
repository into its own sibling folder.

```powershell
git clone https://github.com/GeorgeFejer91/pps-kit-paper.git pps-kit-paper
```

The [earlier Behavior Research Methods draft](behavior-research-methods/manuscript/README.md)
and its evidence records remain available here as source material for the paper.

Each journal-specific workspace should keep manuscript source, templates,
figures, and provenance notes separate from runtime code, local participant
outputs, validation artifacts, and private source PDFs. Do not place raw
participant data, generated acquisition outputs, private reviewer notes, or
unlicensed third-party assets here.
