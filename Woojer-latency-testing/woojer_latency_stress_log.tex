\section{Scope}

This log tracks an isolated Woojer audio pass-through latency workflow. The
measurement target is the audio signal emitted by the Woojer output after a
Komplete Audio 6 MK2 output pulse is sent into the Woojer. This is not a
Woojer mechanical vibration onset measurement and must not be interpreted as
participant tactile perception latency.

\section{Protocol Scaffold}

The first-run baseline state patches Komplete Output 3 directly to Komplete
Input 3. The Woojer-loop state patches Komplete Output 3 into the Woojer analog
input and routes the Woojer audio output back to Komplete Input 3. Both states
use the native Komplete ASIO driver at 44.1 kHz, requested latency 0.010 s,
blocksize 256, safe default amplitude 0.03, and a hard digital amplitude cap of
0.10.
